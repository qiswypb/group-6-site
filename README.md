# GLAM.exe – Y2K Fashion Store

## Project Overview

GLAM.exe is a Y2K-inspired online fashion store created as part of our group assignment. Our website showcases fashion products and provides visitors with information about our brand.

## Technologies Used

- HTML5 – Used to structure the webpages.
- CSS3 – Used to style the website.

## Website Pages

- Home – Introduces our fashion store.
- About Us – Provides information about our brand.
- Products – Displays our fashion products.
- Contact – Provides contact information and an enquiry form.

## How to Run

1. Download or clone the repository.
2. Open the project folder.
3. Double-click `index.html`.
4. The website will open in your web browser.
